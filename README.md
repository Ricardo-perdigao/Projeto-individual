## 🌌 Sobre o Projeto

  Este é o meu **projeto individual desenvolvido juntamente com a faculdade de tecnologia SPTECH**, onde trago a história e elementos da cultura celta, explorando sua simbologia, tradições e crenças, misturado com literatura e gastronomia, sendo ambas minhas paixões.
  O projeto conta também com **Login e cadastro de usuários**, desenvolvido como parte das competências para o estudo em desenvolvimento Full Stack.
  O nome faz referência ao **Triskelion**, símbolo celta de movimento e equilíbrio entre corpo, mente e espírito — valores que inspiram o conceito do site.

---

## 🎯Objetivo
- Desenvolver um projeto legado e único com base nas diretrizes do curso da SPTech.
- Aplicar conceitos vistos em aula, como API, desenvolvimento HTML, CSS e JS, e junção com banco de dados.
- Criar um site que possa servir de material de estudos para quem se interessar.
